# Public sources

Groundwork compiles bounded projections from seven San Francisco public
datasets. Links identify the source; they do not grant redistribution rights.

| Source | Groundwork use |
| --- | --- |
| [Parcels — Active and Retired](https://data.sfgov.org/Geographic-Locations-and-Boundaries/Parcels-Active-and-Retired/acdm-wktn/about_data) | Parcel identity and geometry |
| [San Francisco Development Pipeline](https://data.sfgov.org/Housing-and-Buildings/San-Francisco-Development-Pipeline/6jgi-cpb4/about_data) | Development projects, status, and unit counts |
| [Building Permits](https://data.sfgov.org/Housing-and-Buildings/Building-Permits/i98e-djp9/about_data) | Permit records and status |
| [Assessor Historical Secured Property Tax Rolls](https://data.sfgov.org/Housing-and-Buildings/Assessor-Historical-Secured-Property-Tax-Rolls/wv5m-vpq2/about_data) | Assessment and tax-roll history |
| [Affordable Housing Bonus Program eligible parcels](https://data.sfgov.org/d/fizh-zaxt) | Historical program eligibility |
| [100-Year Storm Flood Risk Zone](https://data.sfgov.org/d/jzu3-4yxp) | Mapped hazard context |
| [311 Cases](https://data.sfgov.org/City-Infrastructure/311-Cases/vw6y-z8j6/about_data) | Nearby neighborhood signals, never parcel facts |

The tracked demo release contains only selected public projections with source
identity, retrieval dates, and SHA-256 manifests. It contains no credentials,
private records, unrestricted source dump, or third-party 3D payload.
